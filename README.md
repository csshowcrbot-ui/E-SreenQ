# E-ScreenQ 癌症篩檢問卷個管系統

竹山秀傳醫院 ‧ 衛生福利部國民健康署公版紀錄表 (平板電子化自填與醫護衛教系統)

## 專案概述

E-ScreenQ 是一套專為醫療院所及社區巡迴篩檢車打造的整合式公費癌症篩檢電子表單與個案管理系統。系統支援全版寬螢幕 / 平板 Kiosk 模式填報、觸控手寫簽名、1:1 國健署標準公版 A4 列印與 PDF 匯出、以及個管師與專科醫師判讀登錄後台。

### 支援之六大篩檢表單

1. **胃幽門桿菌篩檢問卷 (平板端)**
   - 依國健署【附表八之四】標準規範設計
   - 整合個人胃部疾病史、家族胃癌病史、用藥史與快篩抗原檢驗結果追蹤
2. **口腔黏膜檢查表 (受檢者自填端 + 醫師初檢診斷)**
   - 依國健署【AT287】標準規範設計
   - 提供 18 歲以上原住民及 30 歲以上嚼檳榔/吸菸者篩檢
   - 整合牙科/耳鼻喉科專科醫師互動式人體解剖病灶點位標記、切片與轉介追蹤
3. **定量免疫法糞便潛血檢查問卷 (FIT)**
   - 依國健署【附表五之四】標準規範設計
   - 採便管條碼登錄、糞便檢體檢驗數值 (ng/mL) 錄入與大腸鏡確診追蹤
4. **子宮頸抹片檢查表**
   - 依國健署【附表三之四】標準規範設計
   - 婦女性生活、月經史、避孕及子宮手術史填寫
   - 完整支援 Bethesda 系統細胞病理學分類代碼判讀與處置指引
5. **胸部低劑量電腦斷層檢查 (LDCT)**
   - 依國健署 115 年最新公版【附件一之三（個案同意書）、附件一之四（紀錄表單）】規範設計
   - 重度吸菸史（包-年計算）與直系血親家族史資格檢核
   - 完整支援 ACR Lung-RADS v2022 評級分類、結節象限及 Modifier S 標註
6. **婦女乳房 X 光攝影檢查表**
   - 依國健署 114 年 1 月最新修訂版【附表四之四】規範設計
   - 支援院內與巡迴車服務模式、月經/生育/用藥史、血親乳癌家族史年齡表
   - 提供左/右乳房互動式圓形象限（外上/內上/外下/內下/乳暈）自覺硬塊標記
   - 支援放射科專科醫師 BI-RADS 0~5 評級分類與臨床處置建議

## 系統特色

- **100% 滿版 / 全螢幕自適應**：針對醫療平板自填與桌上型個管端進行全版響應式優化。
- **數位親筆簽名與 SHA-256 存證**：支援 HTML5 Canvas 手寫簽章，並計算 SHA-256 雜湊以符合醫療防偽與資安要求。
- **1:1 國健署公版 A4 套印**：支援瀏覽器直接套印或匯出 PDF，格線排版嚴格對齊國健署公告標準。
- **個管師與醫師後台 (Admin Dashboard)**：全表單集中監控、篩檢類別過濾、狀態篩選、作廢紀錄管理與操作稽核紀錄 (Audit Log)。

## 技術架構

- **前端 (Frontend)**
  - React 18 / TypeScript
  - Vite 8
  - Lucide React 圖標庫
  - 原生 CSS3 響應式佈局
- **後端 (Backend)**
  - Node.js / Express
  - JSON 檔案型資料庫持久化存取
  - RESTful API 設計

## 安裝與執行說明

### 1. 環境需求
- Node.js 18+
- npm / yarn / pnpm

### 2. 後端伺服器啟動
```bash
cd backend
npm install
node server.js
```
後端預設運行於 `http://localhost:3001`。

### 3. 前端開發環境啟動
```bash
cd frontend
npm install
npm run dev
```
前端預設運行於 `http://localhost:5173`。

### 4. 前端生產環境建置
```bash
cd frontend
npm run build
```
建置產物將輸出至 `frontend/dist` 目錄。
